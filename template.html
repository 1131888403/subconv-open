🏷️ 节点名标注

用于判断机场是否复用入口：同一 server:port 或同一解析 IP 通常代表复用入口；解析使用阿里 DoH，失败时自动回退显示域名。复用计数始终按订阅全量统计，不随删减变化。

✂️ 节点删减

支持 关键词（匹配节点名）、type:hysteria2、port:34567、re/^🇭🇰/i；加 ！ 前缀表示豁免不删。多个词之间是「或」，命中任一即删。
删减只影响本机生成的配置与导出；中转链接由服务器从源站重新拉取，不会携带这里的删减。

⑤ 中转链接 （进阶功能）

将订阅 URL 绑定到服务器，生成一个稳定的客户端订阅链接。适合分享订阅或给不支持订阅更新的客户端使用。

🔗 新订阅链接用当前 URL 和 UA 创建个人中转链接，可直接粘贴到客户端订阅。
⚠️ 中转链接与本地操作互斥
中转链接由服务器从原始订阅源重新拉取，浏览器本地做的以下修改不会传递到中转链接中：
• 节点删减（关键词过滤、手动 ✕ 删除、复用去重）— 中转链接始终返回全量节点
• IP 解析结果（"解析域名为 IP"的缓存）— 服务器使用自己的 DNS
• 标注模式在生成时固定 — 链接创建时会记录当时的标注模式（不标注 / 地址:端口 / IP:端口 / 仅端口），后续切换标注模式，已有链接不会自动更新。如需新模式请重新生成链接。

中转链接只记录：原始订阅 URL、所选 UA、标注模式。本地删减和 IP 解析一概不传递。
建议：先确认节点列表，再决定是用「生成配置」（带删减）还是「中转链接」（原始全量）。
ℹ️ 支持范围与技术说明
输入：Base64 URI 列表、明文 URI 列表、Clash / Clash Meta YAML（含 flow 风格 { }）、sing-box JSON、Surge CONF。
协议：VMess、VLESS（Reality + xtls-rprx-vision）、Trojan、SS / SS2022、SSR、Hysteria2、TUIC、WireGuard、AnyTLS、Socks5 / HTTP。
输出：Clash YAML、sing-box JSON、v2ray Base64 订阅、Surge、Quantumult X。
隐私：转换全部在本机浏览器完成；除你主动选择的抓取代理外，不向任何第三方发送数据。
